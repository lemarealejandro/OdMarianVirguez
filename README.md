# Sitio Web Oficial - Dra. Marian Virguez (Odontología Especializada)

Sitio web oficial desarrollado en **React + Vite** y optimizado para presentación médica, agendamiento y captación de pacientes.

## Características
- Presentación de servicios dentales integrales
- Sistema multi-idioma (Español / Inglés)
- Diseño responsivo y moderno
- Enlace directo al Portal Clínico MCVD

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Build de Producción
```bash
npm run build
```
